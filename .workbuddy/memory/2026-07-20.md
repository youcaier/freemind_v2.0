## 修复部分节点双击无法编辑的问题

- 用户反馈：部分节点无法双击进入编辑状态，右键菜单编辑正常
- 回退上次基于 `mousedown` 时间戳的双击检测方案
- 重新定位原因：`mousedown` 中调用 `onSelect` 会导致 `selectedId` 状态更新，节点重渲染后破坏双击事件（`dblclick`）的 target 一致性，部分节点因此无法识别双击
- 修复方案：
  - 移除 `handleNodeMouseDown` 中的 `onSelect` 调用，选择逻辑完全交给 `click` 事件处理
  - 在 `NodeView` 中基于 `click` 事件做 300ms 双击检测，第一次点击选中，第二次点击进入编辑
  - 拖拽结束后在 `handleMouseUp` 中调用 `onSelect` 保持被拖拽节点选中
- 修改文件：`src/components/MindMapCanvas.tsx`
- 自测：
  - 使用 puppeteer 在浏览器自动化测试中验证 root、子节点、孙节点、带 Markdown 子元素（`<strong>`）节点的双击编辑
  - 测试结果：所有节点双击均可进入编辑状态
  - 选择测试：单击节点可正常选中
